# Ear-Training Targets

## English (General American)

**Priority contrasts**
- /iː/ vs /ɪ/: *sheep / ship*, *beat / bit*, *leave / live*
- /uː/ vs /ʊ/: *fool / full*, *pool / pull*
- /æ/ vs /ɛ/ vs /ʌ/: *bad / bed / bud*, *pan / pen*
- /θ/ vs /s/ vs /f/: *think / sink / fink*
- /ð/ vs /d/ vs /z/: *then / den / zen*
- /w/ vs /v/: *west / vest*, *wine / vine*
- /ɹ/ vs /l/: *right / light*, *collect / correct*
- Final voicing: *back / bag*, *rice / rise*, *seat / seed* (vowel length is the cue)
- Stressed vs unstressed pairs: *record* (noun) / *record* (verb), *present*

**Connected speech**
- Flapping: *better* ≈ "bedder", *what a day* ≈ "wuh-da-day"
- Reductions: *want to → wanna*, *going to → gonna*, *did you → didja*, *what do you → whaddaya*
- Linking: *pick it up* → "pi-ki-dup"
- Weak forms: *can* /kən/ vs *can't* /kænt/ (the vowel is the clue)
- Dropped /t/ in clusters: *next day* → "nex day"

## French (Parisian)

**Priority contrasts**
- /y/ vs /u/ vs /i/: *rue / roue / ri*, *tu / tout / ti*
- /e/ vs /ɛ/: *été / était*, *les / lait*
- /ø/ vs /œ/: *peu / peur*, *jeûne / jeune*
- Nasal vs oral: *beau / bon*, *pas / pan*, *mais / main*
- Singular vs plural and masculine vs feminine, which can be audible only in liaison or vowel changes: *petit ami / petite amie*
- Voicing: *bon / pont*, *dans / tant*

**Connected speech**
- Liaison: *les amis* → /le.za.mi/, *un grand homme* → /ɛ̃ ɡʁɑ̃.tɔm/
- Enchaînement: *elle arrive* → "é-la-rive"
- Dropped e muet and elision: *je ne sais pas* → "chais pas", *tu es* → "t'es", *il y a* → "y'a"
- Fast speech: *c'est pas vrai* → "s'pa vrai"

## Swedish (Standard / Central Swedish)

**Priority contrasts**
- Vowel and consonant length: *tak / tack*, *mat / matt*, *ful / full*, *vila / vill*
- Vowel quality: /yː/ vs /iː/ vs /ʉː/: *sy / si / su*, *ny / ni / nu*
- /øː/ vs /ɛː/: *hör / här*
- /ɧ/ vs /ɕ/: *sju / tju* (compare *sjukhus* and *tjugo*)
- Retroflexes: *kort / kot*, *bord / bod*, *barn / ban*
- Pitch accent 1 vs 2: *anden* (duck) vs *anden* (spirit)

**Connected speech**
- Dropped consonants in everyday speech: *jag → ja*, *det → de*, *och → å*, *inte → inte / int'*, *mycket → mycke*
- Reductions: *vad har du → va ha du*, *jag tycker → ja tycker*
- Final syllables of infinitives lose the final E sound (*att göra → å göra*)
